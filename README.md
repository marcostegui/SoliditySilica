# SoliditySilica

SoliditySilica enables high-performance, autonomous data management through real-time processing and auto-scaling, leveraging a robust framework manager.

With SoliditySilica, you get a lightweight tool that stays out of your way.

**What you get**

- SoliditySilica enables high-performance, autonomous data
- management through real-time processing and

## Installation

1. Clone the repository: `git clone https://github.com/vishalrankhamb/SoliditySilica.git`
2. `cd SoliditySilica`
3. Install in editable mode: `pip install -e .`

## Configuration

SoliditySilica is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
